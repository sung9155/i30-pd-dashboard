# DCT 클러치 값 확인 안내

7단 DCT 차량 오너분들께 부탁드리는 확인입니다. 계기판 앱이 변속기(TCU)에서 **클러치 잔량일지도 모르는 값**을 하나 읽어 옵니다. 진짜 잔량인지 확인하려고 합니다.

- 예전 카드(`DCT 잔량 후보`, A·B 두 쌍, `22 01A6`)는 둘 다 잔량이 아닌 것으로 확인되어 v1.17.10에서 뺐습니다. 그 값은 클러치 학습표였습니다.
- 지금 카드는 `22 01A5`의 값 한 쌍입니다. 개발자 차량(주행 10만 4천 km)에서 **97.1 / 97.0**이 나왔습니다. 잔량이라고 보기엔 많이 남은 편이라 아직 확정하지 않았습니다.

## 화면에서 찾기

1. 계기판 앱을 **v1.17.10 이상**으로 설치합니다.
2. 시동을 켜고 **`전체 조망`** 화면을 엽니다.
3. **`DCT 값 확인용 (01A5)`** 카드를 찾습니다.

   ```
   DCT 값 확인용 (01A5)
   홀수단              97.1
   짝수단              97.0
   잔량인지 확인 중 · 주행거리와 함께 알려 주세요
   ```

   - 홀수단(1·3·5·7단)·짝수단(2·4·6단) 순서도 추정입니다.
   - 앱은 30초마다 한 번 물어봅니다. 화면을 연 직후 `—`로 보이면 잠시 기다려 주세요.
   - 6단 수동 차량에서는 이 카드가 나오지 않습니다.

앱은 변속기에 값을 **읽기만** 요청합니다(UDS `22 01A5`). 초기화, 학습, 설정 변경은 보내지 않습니다.

## 알려 주기

진단기가 없어도 됩니다. **주행거리와 카드 값**만 있으면 됩니다. 잔량이라면 많이 탄 차일수록 값이 낮아야 하므로, 여러 차의 값을 모으면 확인할 수 있습니다.

**[Issues → New issue](https://github.com/sung9155/i30-pd-dashboard/issues/new?title=DCT%20%ED%81%B4%EB%9F%AC%EC%B9%98%20%EA%B0%92%20%ED%99%95%EC%9D%B8%3A%20)** 에 아래를 남겨 주세요. 제목은 미리 채워져 있습니다.

| 항목 | 예 |
|---|---|
| 차량 | i30 PD 1.6 T-GDI 7DCT, 2019년식 |
| 주행거리 | 104,000 km |
| 카드 값 | 홀수단 97.1 / 짝수단 97.0 |
| (있으면) 진단기 값 | 클러치1 잔량 62 %, 클러치2 잔량 64 % — 진단기·앱 이름도 |
| (있으면) 클러치 교체 이력 | 2023년 8만 km에 교체 |

- 진단기 값이 마모량(사용량)으로 나오면 그대로 적어 주세요. `100 − 마모량`으로도 비교합니다.
- 사진을 올릴 때는 번호판과 차대번호(VIN)를 가려 주세요.
- 카드가 계속 `—`이면 그 사실도 알려 주세요. 가능하면 [진단 기록](https://github.com/sung9155/i30-pd-dashboard/blob/main/INSTALL.md#문제-알리기-진단-기록)(설치기의 `진단기록`)을 함께 보내 주세요.

## 확인되면

여러 차량에서 주행거리나 진단기 값과 맞으면 카드를 **`DCT 클러치 잔량 홀 / 짝`**으로 바꿉니다. 맞지 않으면 카드를 빼고 다른 값을 찾습니다.
