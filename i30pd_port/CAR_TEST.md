# 실차 시험 체크리스트

## 2026-11-04 점심 (우리 차, 7DCT)

시험 빌드: 테스트 릴리스(`test` 태그 = beta a9b634c, v1.8.0 + 진단 요청 시험). 폰 설치 앱은 v1.8.0(versionCode 5).

### 미리 (점심 전)
- [ ] 설치기에서 `2) 테스트`로 대시보드 설치
- [ ] 폰 설치 앱이 v1.8.0(versionCode 5)인지 확인

### 출발 전, 정차 중 (5분)
1. [ ] 폰 설치 앱 **[주행 기록]** 시작
2. [ ] 설정 → RPM → **변속 목표**를 3000 rpm으로 낮춤 (공도에서 6000까지 안 돌리려고)
3. [ ] 같은 화면 **변속 알림음** 켜기 → **알림음 종류**를 다섯 번 눌러 샘플 듣기
   - 소리가 나는지 / 첫 "삐"가 잘리는지 / 음량
   - 마음에 드는 소리로 두기
4. [ ] v1.8.0 화면 조작 (차에서 처음)
   - 플로팅 버튼 아이콘이 잘 보이는지
   - 택시 **운행 시작 → 운행 종료**
   - 제로백 **측정 준비 → 취소**
   - 랩 타이머 탭 → 길게 → 길게

### 주행 1: 알림음만 (10분 이상)
- [ ] 3000 rpm을 넘길 때마다 **한 번씩** 울리는지
- [ ] 연달아 울리지 않는지
- [ ] 라디오·내비 위에서 들리는지

### 정차: 엔진 사운드 켜기 + 기울기 미션
- [ ] 설정 → 사운드 → **엔진 사운드** 켜기 (출력 경로 `알림 채널 · 앞 스피커`)
- [ ] 오토홀드 끄기·켜기 3번
- [ ] 오토홀드 켜고 평지 5초 정차
- [ ] 오토홀드 끄고 오르막 정차 후 출발
- [ ] 주차하며 후진

### 주행 2: 엔진음 + 알림음 (10분 이상)
- [ ] 알림음이 엔진음 위에 섞여 들리는지
- [ ] **알림음이 끝난 뒤에도 엔진음이 계속 나는지** ← 가장 중요
- [ ] (선택, 동승자) 엔진 사운드 끄고 8비트·아케이드에서 2500 rpm 넘게 밟다 뗄 때 불꽃

### 끝, 시동 끄기 전
- [ ] 변속 목표 기본값으로 되돌리기 (이름 쪽을 누름)
- [ ] [주행 기록] → **[기록 끝]** → zip 공유
- [ ] 설치기 **[진단 기록]** 공유 (`OBD probe` 줄 = 진단 요청 시험 응답, 소리 로그도 여기)
- 전체 30분 이상 주행해야 오일 온도 값을 볼 수 있음
